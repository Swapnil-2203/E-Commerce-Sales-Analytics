# E-Commerce-Sales-Analytics
E-Commerce Sales Analysis project using Excel, MySQL, and Power BI.

## Project Overview

This project focuses on analyzing e-commerce sales data to identify key business insights related to revenue, profit, orders, product categories, customers, cities, and countries.

The project demonstrates the complete data analysis workflow, including data handling, SQL analysis, and interactive dashboard creation.

## Tools Used

- Excel – Data cleaning and initial data exploration
- MySQL – Data analysis using SQL queries
- Power BI – Interactive dashboard and data visualization
- GitHub – Project documentation and portfolio hosting

## Dashboard Features

The Power BI dashboard includes:

- Total Revenue
- Total Profit
- Total Orders
- Revenue by Category
- Revenue by Sub-Category
- Revenue by City
- Revenue by Country
- Revenue Trend by Order Date
- Interactive filters for Country and Category

## Key KPIs

The dashboard provides a quick overview of:

- Total Revenue
- Total Profit
- Total Number of Orders
- Sales performance across different categories
- Sales performance across different locations
- Revenue trends over time

## Project Workflow

1. Collected and prepared the e-commerce sales dataset.
2. Cleaned and explored the data using Excel.
3. Performed data analysis using MySQL and SQL queries.
4. Imported and transformed the data in Power BI.
5. Created measures and KPIs for Revenue, Profit, and Orders.
6. Built an interactive dashboard with charts, maps, and slicers.
7. Published the project files and documentation on GitHub.

## Dashboard

The dashboard provides an interactive view of e-commerce sales performance.

Users can filter the data by:

- Country
- Product Category

The visuals update dynamically based on the selected filters.
